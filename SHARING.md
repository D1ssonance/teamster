# Sharing Guide

This directory contains fully anonymized documentation of an agent router
implementation with semantic roles and automatic fallback.

## Quick Start for Recipients

1. Read [README.md](./README.md) first
2. Review [ARCHITECTURE.md](./ARCHITECTURE.md) for visual overview
3. Dive into [implementation/](./implementation/) for Phase 2 details
4. Check [RESULTS-AND-LESSONS.md](./RESULTS-AND-LESSONS.md) for key insights

## What's Included

- Complete architecture documentation
- Phase 2.1: Session router generation
- Phase 2.2: Automatic fallback execution
- Lessons learned from real implementation
- Anonymized pseudocode examples
- Configuration templates
- Safety and privacy policies

## Anonymization

All content is fully anonymized:
- No real model names (uses provider-a/model-1 placeholders)
- No project names or internal domains
- No credentials or endpoints
- Generic patterns applicable to any implementation

## Intended Use

- Reference for similar implementations
- Learning architectural patterns
- Understanding trade-offs and pitfalls
- Adapting error classification strategies
- Implementing semantic role routing
